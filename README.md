# First Find


First find is a command that searches through file contents for a pattern/word and outputs the first instance that contains it. This is useful for seeing only first instances of a word or pattern in a file. 


The command is run from the terminal using Node.js.


Example:


node ff.js hello test.txt


hello is the word search and test.txt is the file.


First Find combines the commands grep and head. grep searches for the pattern and head limits the output. 


I asked AI to explain what the commands grep and head do so I could better understand their functionality in this command. 


AI helped my understanding of the core commands in the code.


I had to independently understand the code and how it combines the two commands for First Find to function.
